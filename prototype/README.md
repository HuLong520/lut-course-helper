# LUTHelper HTML 原型

## 打开方式

原型不依赖构建工具，但使用相对路径加载脚本和样式，推荐通过本地静态服务器打开，而不是直接双击 HTML。

在项目根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory LUTHelper/prototype
```

然后使用最新版 Microsoft Edge 打开：

- 登录页：<http://127.0.0.1:8765/login.html>
- 主界面：<http://127.0.0.1:8765/index.html>

## 演示登录

登录页会校验学号、密码和验证码格式。原型阶段可点击验证码图片查看刷新效果，再填入任意 4 位字母数字验证码并点击“进入工作台”。

## 可操作内容

- 登录账户下拉、新增账号、密码明文切换、验证码刷新。
- 三个主页面切换。
- 课程类型、校区、关键词筛选和高级筛选。
- 表格列显示/隐藏菜单。
- 勾选课程并批量加入抢课队列。
- 重复教学班忽略/移动弹窗。
- 课程组展开、开始、暂停、停止。
- 组内拖拽调整首选/备选顺序。
- 全局定时设置、倒计时和模拟触发。
- 日志抽屉展开、筛选、清空、导出。
- 全校课程模拟加载、筛选、加入待选篮子。
- 已选课程详情、周次切换、课表冲突标记。

## 说明

原型使用 `assets/mock-data.js` 中的占位数据，不访问学校接口，不包含真实账号或个人信息。

字体从 Google Fonts CDN 加载；加载失败时回退到 Windows 系统字体。图标全部是内联 SVG。
