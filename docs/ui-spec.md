# LUTHelper 界面规范 v1

## 1. 设计方向

LUTHelper 是一个高频、长时间运行的桌面选课工具。界面不追求展示型大屏感，也不沿用旧版的蓝紫渐变、Emoji 标题和文本符号按钮。

视觉关键词：

- 暖白、克制、清晰
- 青绿色作为唯一主强调色
- 高信息密度，但用留白和层级避免拥挤
- Fluent 桌面壳 + 轻量编辑部式排版
- 状态必须同时由文字、图标和颜色表达

主界面以 1440×900 为设计基准，同时保证 1280×720 和 1024×700 可用。

## 2. 色板

所有颜色定义在 `prototype/assets/styles.css` 的 `:root`，Qt 实现时在 `theme.py` 使用同名 token。

| `--surface` | `#fffdf8` | 卡片、弹窗、抽屉 |
| `--surface-soft` | `#f9f6ef` | 次一级背景、输入框 |
| `--surface-tint` | `#eef7f2` | 青绿色淡底 |
| `--ink` | `#1b2924` | 主文字 |
| `--ink-soft` | `#40504a` | 次文字 |
| `--muted` | `#79827d` | 辅助说明 |
| `--faint` | `#a9aea9` | 占位、时间戳 |
| `--line` | `#e3ded2` | 普通描边 |

| `--teal` | `#147d6d` | 主按钮、主状态 |
| `--teal-strong` | `#0d675a` | 主按钮悬停 |
| `--teal-soft` | `#dcefe8` | 选中背景 |

| `--nav-deep` | `#10241e` | 导航深色渐变终点 |

### 2.1 使用规则

- 青绿色只用于主操作、在线/成功状态和当前选中项。
- 琥珀色只用于定时、暂不可确定、需用户注意的状态。
- 红色只用于失败、冲突、停止和破坏性操作。
- 禁止用颜色作为唯一信息通道，必须配合文字或图标。
- 不使用纯黑 `#000` 和纯白大面积背景。
- 不使用紫色作为主色，不使用高饱和霓虹色。

## 3. 字体与排版

### 3.1 字体

- 英文和数字：`Manrope`，CDN 加载；失败时回退 `Segoe UI Variable`。
- 中文：`Noto Sans SC`，CDN 加载；失败时回退 `Microsoft YaHei UI`。
- 正式 Qt 版本不打包字体，使用系统自带的 `Segoe UI Variable` 和 `Microsoft YaHei UI`。
- 日志和教学班 ID 使用 `Cascadia Mono` 或 `Consolas`。

### 3.2 字号

| 层级 | 字号 | 字重 |
|---|---:|---:|
| 页面主标题 | 29px | 700 |
| 视觉稿大标题 | 38px | 700 |
| 卡片标题 | 12–13px | 800 |
| 正文和表单 | 10–11px | 500–700 |
| 辅助说明 | 8–9px | 500–600 |
| 表头 | 9px | 700 |
| 表格正文 | 10px | 500–700 |
| 日志正文 | 8px | 400–700 |

### 3.3 排版规则

- 页面标题使用紧凑字距 `-0.035em`。
- 英文小标题使用 0.11–0.13em 字距，全部大写。
- 正文行高约 `1.5`，登录视觉区说明文字约 `1.8`。
- 不使用旧版的 `🎓`、`⚡`、`▶`、`■` 等 Emoji 或文本符号代替图标。

## 4. 间距、圆角与阴影

### 4.1 间距

采用 4px 基准：

- 4：紧凑控件内部
- 6–8：控件组、表格单元格
- 10–12：卡片内部
- 14–18：卡片区块
- 22–26：页面外边距
- 30–48：登录页大区块

### 4.2 圆角

| Token | 值 | 用途 |
|---|---:|---|
| `--radius-sm` | 8px | 输入框、小按钮 |
| `--radius-md` | 12px | 提示条、菜单 |
| `--radius-lg` | 18px | 主卡片 |
| `--radius-xl` | 26px | 登录主卡 |

小控件圆角不应超过 10px；主卡片不应使用胶囊形圆角。

### 4.3 阴影

- `--shadow-sm`：卡片默认，极淡。
- `--shadow-md`：InfoBar、菜单、日志抽屉。
- `--shadow-lg`：模态框和登录主卡。
- 禁止给每个控件都加阴影；阴影用于表达层级，不用于装饰。

## 5. 应用壳与导航

### 5.1 左侧导航

- 宽 224px；窗口小于 1280px 时收为 80px 图标栏。
- 深墨绿色背景，顶部为品牌标识。
- 主导航仅三页：课程、全校课程、已选课程。
- 当前项使用淡青绿背景 + 左侧 3px 指示条。
- “课程”导航显示当前课程组数量。
- 导航底部显示当前选课批次，窗口收窄时隐藏。

### 5.2 顶栏

- 高度约 72px，半透明暖白背景并带模糊。
- 左侧显示工作空间、当前页面和在线状态。
- 右侧依次为：批次下拉、静音按钮、帮助、学生账号区、退出登录。
- 学生账号区显示姓名、学院摘要、头像首字。
- 不使用底部状态栏；任务统计放在任务区和账号区。

### 5.3 页面标题

每页顶部使用：

1. 英文小标题 + 短横线
2. 中文主标题
3. 一句操作说明
4. 右侧页面操作按钮

主标题不写成营销口号堆叠，保持一个明确动作或页面主题。

## 6. 课程页

### 6.1 布局

- 左右双栏，默认比例约 `62 / 38`。
- 左栏：课程检索卡片。
- 右栏：抢课队列卡片。
- 两栏最小高度为视口高度减去顶部标题和边距。
- 窗口小于 960px 时改为上下堆叠，课程区在上，任务区在下。

### 6.2 课程检索

- 卡片头部：标题、教学班数量、列配置、筛选展开按钮。
- 工具行：课程类型分段按钮、校区下拉、关键词搜索。
- 类型：系统推荐、方案内、体育、公选。
- 高级筛选默认收起，包含“仅看有余量”和“时间冲突”。
- 默认显示列：加入、课程、余量、教师、时间地点、状态、更多。
- 其他列通过列菜单临时显示或隐藏，不跨会话保存。

### 6.3 课程表格

- 表头浅米色，粘性定位。
- 行高约 52px，不显示纵向网格线。
- 课程名 1 行省略，完整名称通过课程详情查看。
- 课程代码和课序号为第二行小字。
- 余量使用细进度条 + `已选/容量` 数字。
- 满员显示红色状态胶囊；冲突显示琥珀色或红色冲突标记。
- 每行使用圆形加号按钮直接加入抢课队列；成功后变为实心青绿圆形对勾，再次点击即可取消加入。
- 已加入行使用极淡的青绿底色和左侧 2px 强调线。
- 不提供底部批量加入栏；点击课程名打开详情；更多菜单提供查看、加入和移除。

### 6.4 课程详情抽屉

- 宽 400px，从右侧滑入。
- 顶部显示课程名、课程代码、课序号和关闭按钮。
- 状态行显示可选/满员/冲突、校区和课程性质。
- 信息网格：教师、教学班、学分学时、容量、开课单位、教学班 ID。
- 上课安排使用迷你时段列表。
- 冲突时显示红色说明块。
- 从课程页或全校课程页打开时，底部固定“加入抢课队列”和“关闭”按钮。
- 从已选课程页打开时，只显示“关闭”，不提供加入抢课队列。
- 遮罩使用浅色低模糊，查看详情时不能过度压暗其余课程。
- 窗口小于 1280px 时同样以抽屉形式出现。

### 6.5 抢课队列

- 卡片头部：标题、课程组数量、全部开始/停止。
- 参数条：请求间隔、每课线程、抢到即停、预计线程数。
- 预计线程数 >20 显示琥珀色，>50 显示红色，但不阻止操作。
- 全局定时合并为一条精简设置行，包含日期、时间、倒计时和一个启用开关，固定在课程组列表上方。
- 多教学班课程使用可折叠卡片，组头显示课程名、组状态、教学班数量和组级操作；折叠状态保存在课程组模型中，不因重新渲染丢失。
- 只有一个教学班的课程直接显示为紧凑课程卡片，不再套一层任务列表。
- 组内任务卡片显示优先级、班级、教师、校区、时间、容量和尝试次数。
- 首选/备选顺序通过组内拖拽调整；仅未开始时可拖。
- 成功的课程组折叠为一行摘要，显示成功教学班和成功时间。

## 7. 全校课程页

- 左侧课程大表，右侧“待加入教学班”篮子。
- 进入页面后自动加载；顶部只保留“刷新全部课程”，空态不再重复放加载按钮。
- 加载过程中显示进度条和已加载/总数。
- 搜索与校区筛选仅作用于已加载数据，不发送服务器关键词请求。
- 勾选课程后进入右侧篮子；按课程代码自动分组。
- 底部显示将创建的课程组数量，主按钮为“加入抢课队列”。
- 窗口小于 1120px 时篮子移到下方，列表内部改为两列卡片。

## 8. 已选课程页

- 左侧已选课程列表，右侧周课表，默认比例约 `42 / 58`。
- 左侧表格显示课程、教师、星期/节次。
- 退课记录放在左侧底部折叠区；首版不提供退课写操作。
- 右侧周课表为 7 天网格，最小显示 1–10 节，有晚课时扩展到 12 节。
- 周次下拉包含“全部周次”和 1–20 周。
- 课程块按课程名稳定哈希选择 6 个低饱和主题色。
- 冲突课程块使用红色左边框和警示图标。
- 无法排入网格的课程显示在课表下方“未排入网格”列表。
- 点击课程块打开右侧详情抽屉。

## 9. 登录页与登录弹窗

### 9.1 HTML 原型登录页

- 左右分栏主卡：左侧深墨绿色视觉区，右侧登录表单。
- 主卡宽 1020px，最小高度 600px，圆角 26px。
- 左侧展示标题、说明、周课表缩略图和任务小卡。
- 右侧依次为：学号下拉、新增账号、密码、验证码、记住密码、登录按钮。
- 学号下拉包含已保存账号和“新增账号”项；新增时展开新学号输入框。
- 密码框右侧提供眼睛图标切换明文。
- 验证码图片点击刷新，刷新时按钮进入禁用加载态。
- 登录按钮为青绿色主按钮，提交时显示旋转加载圈并禁用重复点击。
- 错误使用表单内红色提示条，不使用系统错误弹窗。
- 登录成功后跳转 `index.html` 进入演示主壳。

### 9.2 Qt 登录弹窗

- 启动后立即显示，不可绕过进入主界面。
- 弹窗内不显示左侧营销视觉区，只保留品牌、表单和状态提示。
- 桌面窗口最小宽度约 480px。
- 验证码图片从内存 `QPixmap` 显示，不写临时文件。
- 自动 OCR 仅在开发构建出现；正式构建隐藏该入口。

## 10. 日志抽屉

- 固定在内容区底部，收起时只露出 46px 手柄。
- 展开时向上覆盖内容，不挤压课程表和任务区。
- 手柄显示记录数、活跃任务数和最近一条日志。
- 工具栏支持课程组筛选、级别筛选、导出当前筛选结果、清空。
- 日志行显示时间、级别和消息；使用等宽字体。
- 正常自动滚动到底部；用户向上滚动后暂停并显示“回到最新”。
- 内存最多 5000 条；正式实现可按 100ms 批处理，原型按需求立即追加。

## 11. 状态、反馈与动效

### 11.1 状态语义

| 状态 | 颜色 | 文案 |
|---|---|---|
| 在线 / 运行 / 成功 | 青绿 | 在线、运行中、已成功 |
| 定时 / 等待 / 提醒 | 琥珀 | 已定时、待开始、需注意 |
| 失败 / 冲突 / 停止 | 红色 | 失败、冲突、已停止 |
| 草稿 / 未开始 / 普通 | 中性灰 | 待开始、草稿 |

### 11.2 反馈

- 成功抢到课程：显示 5 秒自动关闭的 InfoBar，并播放系统提示音；同一课程组只提示一次。
- 定时触发：显示 InfoBar，播放系统提示音。
- 普通失败：只更新任务状态和日志，不弹窗。
- 网络或接口错误：InfoBar 显示简短原因，完整响应写日志。
- 顶部铃铛按钮可临时静音，仅当前会话生效。

### 11.3 动效

- 页面切换：淡入并上移 5px，240ms。
- 筛选面板：淡入并下移 3px，180ms。
- 抽屉：右侧滑入，260ms。
- 模态框：淡入并轻微缩放，200ms。
- 新加入课程组：1.1 秒边框高亮。
- 只做有意义的状态动效，不给所有按钮添加弹跳或旋转。
- 尊重 `prefers-reduced-motion`，Qt 实现提供关闭动画的开关。

## 12. 响应式与高 DPI

### 12.1 断点

| 宽度 | 行为 |
|---|---|
| ≥1280px | 完整导航、左右工作台、固定详情宽度 |
| 1120–1279px | 导航收为图标栏，工作台比例略收紧 |
| 960–1119px | 全校课程篮子下移，任务参数条重排 |
| <960px | 课程页和已选页上下堆叠 |
| <760px | 导航变为底部三项，登录视觉区隐藏 |

### 12.2 高 DPI

- Qt 使用原生高 DPI 缩放，不手动乘缩放系数。
- 在 100%、125%、150% 下检查表格文字、图标和抽屉宽度。
- 图标使用 SVG，确保任意缩放清晰。
- 应用图标沿用现有 `favicon.ico`。

## 13. 可访问性与交互约束

- 所有图标按钮必须有 `aria-label` 或 Qt tooltip。
- 所有可点击行必须有键盘可达的替代操作。
- 焦点环使用青绿色 3px 外发光。
- 模态框打开后焦点进入第一个主要操作，Escape 关闭。
- 不允许单击课程行即加入任务；必须勾选后批量加入。
- 不允许跨课程组拖拽任务。
- 运行中任务禁止调整组内顺序。
- 退出登录或关闭窗口时，有运行任务必须先确认停止。

## 14. 原型验收清单

- [ ] 登录页在 1440×900、1280×720、1024×700 下无横向滚动。
- [ ] 登录校验、验证码刷新、密码显示切换可操作。
- [ ] 三页导航切换正常，窄屏导航收起。
- [ ] 课程类型切换、关键词搜索、校区筛选、高级筛选正常。
- [ ] 列菜单可显示/隐藏列。
- [ ] 勾选课程后批量加入，重复教学班弹窗可忽略或移到末尾。
- [ ] 课程组展开、开始、暂停、停止、任务菜单正常。
- [ ] 组内拖拽可调整首选/备选顺序，跨组拖拽被拒绝。
- [ ] 全局定时可设置、显示倒计时、触发后从首选启动。
- [ ] 日志抽屉可展开、筛选、清空、导出，滚动时不强制回到底部。
- [ ] 全校课程可加载、筛选、加入篮子、批量加入队列。
- [ ] 已选课程页可切换周次、显示冲突、打开课程详情。
- [ ] InfoBar 5 秒自动消失，关闭按钮有效。
- [ ] 页面无控制台错误，不依赖未加载的本地资源。
